7. 다시 여는 조건
============================================================

Stage QA-0은 다음 경우에만 다시 연다.

- required production route 정책 변경
- generated route tree의 public/detail route 계약 변경
- GitHub Pages origin 또는 repository base 변경
- 대표 fixture가 frozen frontend consumer에서 제거되거나 admission 정책이 변경
- prototype route를 production gate에 포함하기로 명시적으로 정책 변경
- Hosted Gate 필수 검사 분류 자체를 버전업
- Hosted / Browser / Semantic failure boundary를 변경

CSS, 이미지 교체, localization, 개별 UI presentation 변경만으로 Stage QA-0 계약을 다시 열지 않는다.
