# Langrisser Future Hub

I am attaching a screenshot of the current desktop homepage draft that was originally created in v0.

Please use the attached screenshot as the primary visual reference.

This is NOT a request to redesign the website from scratch.

Your job is to preserve the current design language, proportions, card style, spacing, white background, rounded corners, soft shadows, blue accents, and cute SD character illustrations as much as possible, while applying only the specific structural changes listed below.

The current visual direction is already close to what I want.

Highest priority rules

Preserve the current visual design.

Apply only the requested structural changes.

Do not add new sections, widgets, features, or navigation systems on your own.

Do not redesign the page into a dashboard, news site, or large wiki homepage.

Focus only on the desktop PC homepage for this iteration.

1. Keep the 3 × 3 main card layout

The 3-column by 3-row grid is one of the most important parts of the current design.

Keep exactly 9 main cards on the desktop homepage.

Use these Korean category names:

업데이트

가챠 배너

전용장비 · 율정

스킨

시공

정기 이벤트

일회성 이벤트

용병

서밋 신규맵

Do not change this into a different number of columns or a different dashboard layout.

The 3 × 3 grid should remain visually balanced and easy to scan.

2. Merge the two space-time categories into one "시공" card

The previous version had separate cards for:

시공의 균열

문 너머 저편

Replace those two homepage cards with one card called:

"시공"

This card will later lead to a subpage where users can choose between:

시공의 균열

문 너머 저편

Do not build that detailed subpage yet.

Just make the homepage structure ready for that future navigation.

3. Add "용병" as one of the 9 cards

Use the space created by merging the two 시공-related cards to add:

"용병"

The final homepage must still have exactly 9 cards.

4. Simplify card content

Each card should contain only:

one cute SD character illustration

one large Korean category title

Remove all small explanatory subtitles under the card titles.

For example, do not show text such as:

"지형 · 배치 정리"

"이벤트 일정 확인"

"출시 예정 장비"

The target users already understand these game categories.

The cards should feel like clear, large navigation buttons rather than information panels.

5. Keep the SD illustrations

The cute SD illustrations are an important part of the visual identity.

They are intentionally used to prevent the site from feeling too rigid, technical, or spreadsheet-like.

Keep them prominent enough to give each card personality, but maintain visual consistency across all 9 cards.

Use consistent:

illustration scale

vertical alignment

spacing

overall visual weight

Do not replace them with plain icons or overly minimal symbols.

6. Simplify the top header

The main cards are already the primary navigation.

Therefore, do not repeat the same categories in the top header.

Remove the category navigation links from the header.

Also remove the search icon for now.

Search will be added later when the site has enough internal character, equipment, and soldier data to make it useful.

Keep the header simple and clean.

A minimal header with:

logo or small site icon

"랑그릿사 모바일"

is enough.

Do not introduce a hamburger menu, mega menu, dropdown navigation, or secondary navigation system in this desktop iteration.

7. Keep the current hero concept

Keep the current overall headline direction:

"랑그릿사 모바일 미래 정보를 한 곳에서"

The site currently focuses on upcoming/future information for the Korean version of Langrisser Mobile.

Do not describe the site as:

a complete Langrisser database

a comprehensive wiki

a full character database

a full equipment database

Those may become long-term goals later, but they are not the current public purpose of the site.

8. Remove the Notice section

Delete the entire "공지사항" section from the homepage.

Community announcements are handled elsewhere.

Do not replace it with:

news

community posts

statistics

update logs

promotional banners

recommended content

The homepage should stay simple.

9. Remove the Recent Updates section

Delete the entire "최근 갱신" section.

Users do not need to see when each sheet was last modified.

Do not replace it with any other dashboard widget.

The homepage should prioritize navigation.

10. Add only one subtle desktop-only information line

Below the 3 × 3 card grid, include a very small secondary line such as:

"미래시 관련 정보는 계속해서 보강됩니다."

This text must NOT look like another clickable card.

Do not place it inside a large bordered container.

It should simply be a subtle supporting message.

For now, this is intended for the desktop version only.

Mobile will be designed separately later.

11. Give the "업데이트" card only slight emphasis

The 업데이트 card is currently the most important entry point because the project began as a future-content information site.

Give it a very subtle visual priority.

Acceptable examples:

slightly stronger blue border

slightly stronger shadow

very subtle background tint

small restrained accent

Do NOT:

make it larger than the other cards

make it full-width

add a large badge

break the 3 × 3 grid

make it visually dominant

The difference should be noticeable only after looking at the page for a moment.

12. Add a non-profit notice to the footer

This project is operated as a non-profit and non-commercial fan information site.

Add a small footer notice such as:

"본 사이트는 비영리·비수익 목적으로 운영되는 팬 정보 사이트입니다."

Also add a short note that game-related images and materials belong to their respective rights holders.

Keep this information visually secondary.

Do not put this disclaimer in the main content area.

If the current footer already contains license or source information, organize everything cleanly together in the same footer.

13. Desktop PC only for this iteration

Do not redesign the mobile version yet.

Do not spend this iteration optimizing a separate mobile layout.

Focus on making the desktop homepage feel finished.

Desktop priorities:

balanced 3 × 3 grid

large click targets

readable Korean typography

consistent card heights

consistent illustration placement

comfortable horizontal spacing

enough whitespace

not excessively tall

14. Prepare the cards for future subpages

Each homepage card will eventually lead to a smaller category page.

The long-term navigation idea is:

Homepage
→ main category
→ smaller clear choices
→ relevant information / Google Sheet

This is intentional.

The target audience includes many older players, so important information should be divided into clear steps instead of being hidden inside one large spreadsheet with many tabs.

However:

Do NOT build all of those subpages now.

For this iteration, only make sure that each of the 9 cards is structured as a clear clickable navigation component that can later link to its own subpage.

15. Important UX philosophy

The homepage should be simple.

Users should immediately understand:

"Which information do I want to open?"

The homepage is not meant to be a content-heavy dashboard.

It is the first navigation layer.

The detailed information will exist deeper in the site.

Use this principle:

Simple at the homepage, more specific as the user goes deeper.

Final visual direction

The desired feeling is:

the simplicity of the current Google Sites homepage + the cleaner and friendlier visual polish of the attached v0 design

Prioritize:

readability

large navigation targets

simple structure

friendly SD artwork

clear visual hierarchy

consistent spacing

desktop usability

Avoid:

unnecessary widgets

news feeds

recent-update feeds

duplicated navigation

search for now

detailed card descriptions

excessive animations

complicated interactions

adding new features without being asked

changing the overall visual identity

Most importantly:

Do not create a new design concept. Refine the attached design into a cleaner and more complete desktop homepage.
